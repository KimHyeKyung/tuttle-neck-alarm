## 📌 프로젝트 소개

하루 종일 모니터 앞에 있다 보면 나도 모르게 목이 앞으로 빠지는 게 신경 쓰여서 만든 앱입니다.
알림창 대신 작은 픽셀 거북이가 화면 아래에서 기어나와 말을 걸어서, 업무 흐름을 끊지 않고 자세를 한 번 돌아보게 해 줍니다.

- **2026.07** 윈도우 버전 배포
- 배포 하루 만에 조회수 **4만 회**
- 사용자 요청을 반영해 **macOS 버전** 추가 배포

---

## 🛠 개발 방식

이 앱은 **AI(Claude)를 활용해** 만들었습니다. 코드는 Claude가 작성했고, 저는 아래 역할을 맡았습니다.

- **기획:** 어떤 순간에, 어떤 방식으로 알려 줘야 거슬리지 않을지 정하고 기능 범위 결정
- **디자인:** 픽셀 거북이 캐릭터와 말풍선 문구
- **검증:** 직접 써 보면서 동작 확인, 수정 방향 정리
- **배포와 운영:** 윈도우, 맥 실행 파일 배포, 홍보, 사용자 피드백 수집과 반영

사용 기술: Python, PyInstaller(실행 파일 패키징)

---

## 🚀 다운로드와 실행

1. 위 파일 목록에서 운영체제에 맞는 파일을 클릭합니다.
   - 윈도우: `거북목알리미_win.zip`
   - 맥: `거북목알리미_mac.zip`
2. 오른쪽 위 `...` 버튼 → **Download**
3. 압축을 풀고 실행합니다. Python 설치는 필요 없습니다.

### ⚠️ 보안 경고가 뜰 때

- **윈도우:** Windows Defender 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
- **맥:** "확인되지 않은 개발자" 경고가 뜨면 앱을 **우클릭 → 열기**를 누르세요.

## 🖥 기능

- 30분마다 🐢가 화면 아래에서 등장
- 말풍선으로 거북목 경고 메시지 표시
- 배경 투명 처리 (거북이만 보임)
- 트레이 아이콘 메뉴
  - **지금 당장 나타내기:** 바로 거북이 부르기
  - **종료:** 프로그램 끄기

### 🔄 컴퓨터 켤 때 자동 실행 (윈도우)

1. `Win + R` → `shell:startup` 입력 → 엔터
2. `거북목알리미.exe` 우클릭 → **바로 가기 만들기**
3. 만든 바로 가기를 열린 폴더에 붙여 넣기
